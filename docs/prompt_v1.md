This is a project to develop a mobile app that can track my weekly goal, quarterly goal and yearly goal as a couple. So that not only both of us can see our shared goals and decisions, but can alos see their own goals, each other can see their partner goals as well. This app should focus on cuteness, fun, and simple UI and interactive. Make it enjoyable to use the app, define goals, and checking goals, and checking in easily as well. I'm also thinking of a gallery platform for just two us, but we can have multiple gallery, which each gallery represent one topic we're discussing/planning/deciding. Within the gallery, we as a couple can customise, promote doing together by customsing, or playing game I don't know. each gallery also have a chat to keep our decision and discussion. I'm not sure if gallery is a correct word, it could be a dashboard, or a thread, or a page, I'm not sure yet. I'm just thinking as it should be interactive, cuteness and us working together.

## Key decisions made during brainstorming (2026-07-10)

- Core focus: **goal tracking first**; galleries support bigger discussions
- Fun flavor: **reactive companion pet — a cute bulldog** (cheerleader, not a chore)
- Check-in: **zero-friction tap progress** on goal cards
- Goal horizons: **linked ladder** (weekly → quarterly → yearly)
- Galleries named **"Corners"**: board with chat + pins + polls; decisions convert to goals
- Bulldog animation: **Rive** state machine
